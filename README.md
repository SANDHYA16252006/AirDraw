# 🎨 AirDraw Pro

AirDraw Pro is a gesture-controlled virtual drawing application built using Python, OpenCV, MediaPipe, and NumPy.

## 🚀 Features

- ✋ Real-time hand tracking
- 🎨 Air drawing using index finger
- 🔵 Multiple brush colors
- 🩹 Eraser tool
- 🗑️ Clear canvas
- 📷 Full-screen camera interface

## 🛠 Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/AirDraw-Pro.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run

```bash
python step5_color_menu.py
```
